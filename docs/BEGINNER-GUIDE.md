## 1. 这是什么东西？

**一句话**：XiaoNai（小奈）是一个"住在 QQ 群里的机器人"，它可以用你自己的 QQ 号，在你的 QQ 群里自动回答问题、查资料、报天气、提醒考试。

**它需要 4 样东西配合工作**：

```
你的电脑（运行程序）
    │
    ├── Python        —— 机器人的"身体"（运行代码的软件）
    ├── 项目代码       —— 机器人的"大脑"（小奈的程序，就是这个仓库）
    ├── API Key       —— 机器人的"聪明来源"（让 AI 大模型替它思考）
    └── NapCat        —— 机器人的"嘴和耳朵"（让 QQ 号能自动收发消息）
```

打个比方：**Python 是身体，代码是大脑，API Key 是请来的 AI 军师，NapCat 是嘴和耳朵。** 缺一样，小奈都不能说话。

## 2. 开始前，确认你有这些东西

| 需要 | 说明 | 没有怎么办 |
|------|------|-----------|
| 💻 一台电脑 | Windows 10/11、Mac、Linux 都行 | 本教程以 **Windows** 为主，Mac/Linux 用户看每步的"其他系统"提示 |
| 🌐 能上网 | 下载软件、申请 Key 都要用 | 无 |
| 📱 一个 QQ 号 | **最好是新注册的小号**，不要用你自己的主号！ | 注册一个就行 |
| 📁 一个文件夹 | 用来放项目代码，比如 `D:\xiaonai` | 教程会教你怎么建 |

> ⚠️ **重要提醒**：建议用一个**专门的小 QQ 号**给机器人用。用主号的话，你的好友会被机器人自动回复打扰，还可能因为"异地登录"被安全限制。

## 3. 第一步：安装 Python

### Windows 用户

1. 打开浏览器，访问 Python 官网：**https://www.python.org/downloads/**
2. 点击黄色的 **Download Python 3.1x.x** 大按钮（选最大的数字）
3. 下载完成后，**双击**安装包
4. **最关键的一步**：安装窗口**最下面**有一个勾选框，写着
   `☐ Add python.exe to PATH`
   **一定要把它勾上！**（不勾的话，后面所有命令都会失败）
5. 点击 **Install Now**（立即安装），等待进度条走完
6. 看到 **Setup was successful**（安装成功）就完成了

**✅ 怎么确认成功了**：按键盘上的 `Win + R`，输入 `cmd` 回车，在黑窗口里输入：

```
python --version
```

看到类似 `Python 3.12.x` 就成功了。看到"不是内部或外部命令"说明第 4 步没勾，重新安装一遍。

### Mac 用户

1. 打开终端（`Command + 空格`，输入 Terminal 回车）
2. 输入 `python3 --version`，如果显示 3.10+ 就跳过
3. 没有的话，去 https://www.python.org/downloads/ 下载 Mac 版安装

### Linux 用户

```bash
sudo apt update && sudo apt install -y python3 python3-pip python3-venv
```

## 4. 第二步：把代码拿到你的电脑上

### 最简单的方法（推荐新手）：下载压缩包

1. 打开本项目的 GitHub 页面
2. 点击绿色的 **Code** 按钮
3. 点击 **Download ZIP**
4. 解压到你想要的位置（比如解压到 `D:\`，会得到一个 `xiaonai-main` 文件夹）
5. 把文件夹重命名为 `xiaonai`（去掉 `-main`），路径变成 `D:\xiaonai`

### 会一点的同学：用 git 克隆

```bash
git clone https://github.com/fieldlu/xiaonai.git
cd xiaonai
```

**✅ 怎么确认成功了**：打开文件夹，能看到 `bridge.py`、`README.md`、`requirements.txt` 这些文件就对了。

## 5. 第三步：打开"命令行"，安装零件

### 5.1 什么是"命令行"？

命令行就是一个**黑色（或白色）的输入框窗口**，你输入文字命令，电脑执行。Windows 里它叫 **CMD** 或 **PowerShell**。

### 5.2 打开命令行

**方法一**：在项目文件夹的地址栏（最上面那条）里，直接输入 `cmd` 然后按回车。

**方法二**：
1. 按 `Win + R`，输入 `cmd`，回车
2. 然后输入 `cd /d D:\xiaonai` 回车（把 `D:\xiaonai` 换成你的项目路径）

> 💡 **提示**：命令行里"复制"是选中文字后按右键或 `Ctrl+V`，"粘贴"是右键。`Ctrl+C` 在命令行里是"中断程序"，不是复制！

### 5.3 确认你在正确的位置

输入：

```
dir
```

（Mac/Linux 用 `ls`）

能看到 `bridge.py`、`requirements.txt` 这些文件，就说明位置对了。

### 5.4 安装依赖（给机器人装零件）

在命令行里输入下面这行，然后回车：

```
pip install -r requirements.txt
```

然后就是等待，看到一大堆英文滚动。**看到最后出现类似下面这样，就是成功**：

```
Successfully installed aiohttp-xxx httpx-xxx ...
```

**🚑 如果失败怎么办**：
- 报错里有 `pip` 不是命令 → Python 没装好或 PATH 没勾，回到第 3 步
- 报错里有 `Microsoft Visual C++` → 去 https://aka.ms/vs/17/release/vs_BuildTools.exe 下载安装，选"C++ 生成工具"，装完重试
- 网速慢/超时 → 用国内镜像源：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 6. 第四步：申请一把"钥匙"（API Key）

机器人需要 AI 大脑来回答问题和理解你的话。你需要在某个 AI 服务商那里申请一把"钥匙"（API Key），填进配置里。

**任选一个就行**（本教程推荐 DeepSeek，申请最简单、国内可用）：

### 方案 A：DeepSeek（推荐，简单）

1. 打开 https://platform.deepseek.com 注册账号
2. 登录后，左侧菜单找到 **API Keys**（API 密钥）
3. 点击 **创建 API Key**（Create API Key）
4. 随便起个名字（比如 `xiaonai`），点击创建
5. **立刻复制**生成出来的一长串 `sk-` 开头的字符串，保存到记事本里
   > ⚠️ 这个钥匙只显示一次！忘了就得重新创建。
6. 充值一点余额（几块钱就够测试很久）—— 在"用量"/"充值"页面

### 方案 B：MiMo（小米，本项目默认模型）

1. 打开 https://opencode.ai 注册
2. 在控制台找到 API Key 页面，创建一把 `sk-` 开头的钥匙
3. 同样保存好

### 方案 C：其他任何 OpenAI 兼容的服务商

只要提供 `base_url` + `api_key` 的都可以。

**✅ 怎么确认成功了**：你的记事本里有一串 `sk-` 开头的长字符串，就叫成功。这串东西是**秘密**，不要发给任何人，不要截图发网上！

## 7. 第五步：安装 NapCat（连接 QQ 的桥梁）

NapCat 是一个程序，它能让你的 QQ 号"开口说话"——自动收发消息。这是整个过程中**最容易卡住**的一步，跟着慢慢来。

### 7.1 下载 NapCat

1. 打开官方文档：**https://napneko.github.io/**
2. 找到"快速开始"/"下载"章节，下载 **Windows 版**（一般是 `NapCat.Shell` 或 `.zip` 压缩包）
   > 如果官网打不开，直接去 GitHub 搜 `NapCatQQ` 的 Releases 页面下载

### 7.2 解压并启动

1. 把下载的压缩包解压到一个文件夹，比如 `D:\NapCat`
2. **先登录电脑上的 QQ 客户端**（用你给机器人准备的小号），保持 QQ 开着
3. 双击运行 NapCat 的主程序（`NapCat.exe` 或 `napcat.exe`）
4. 会弹出一个黑窗口，看到类似 `NapCat ... started` 的字样就说明启动成功

### 7.3 打开 NapCat 的网页控制台（WebUI）

1. 打开浏览器，访问：**http://127.0.0.1:6099/webui**
   > 如果打不开，看黑窗口里显示的端口号（可能是别的数字），用它替换 6099
2. 第一次访问会让你设置一个**访问密码**，随便设置一个记住它（本地工具，不联网）
3. 登录后，找到 **网络配置**（Network）页面

### 7.4 添加 OneBot 连接（关键！）

1. 在网络配置页面，点击 **添加** / **新增连接**
2. 类型选择：**WebSocket 服务器**（WebSocket Server）
3. 协议选择：**OneBot 11**
4. 端口填写：**3001**
5. 保存 / 应用配置
6. 回到 NapCat 主界面，会看到你的 QQ 号已经"登录"了

**✅ 怎么确认成功了**：NapCat 窗口里没有报错，浏览器 WebUI 里能看到"已连接"，就成功了。

> 🚑 **这一步失败了？** 最常见原因是 QQ 号登录态问题：
> - 确保电脑上的 QQ 客户端**先登录**再启动 NapCat
> - 如果要求扫码，用手机 QQ 扫码
> - 小号新注册可能被风控，让机器人 QQ 号先在手机上挂几天正常使用

## 8. 第六步：填写配置文件

### 8.1 创建 .env 文件

1. 回到项目文件夹 `D:\xiaonai`
2. 找到文件 `.env.example`
   > ⚠️ 注意：这个文件叫 `.env.example`，**前面有一个点**，开头不是"下划线"
3. **复制一份**：右键点击它 → 复制 → 在空白处右键 → 粘贴
4. 把复制出来的文件改名为 `.env`（就 4 个字符，`.` `e` `n` `v`，没有 `example` 了）
   > Windows 可能提示"修改扩展名可能导致文件不可用"，点**是**就行

### 8.2 用记事本编辑

1. 右键 `.env` → 打开方式 → **记事本**
2. 找到这些行，改成你自己的：

```
MIMO_API_KEY=你的MiMo钥匙           ← 如果你用 MiMo，填第6步申请的钥匙
DEEPSEEK_API_KEY=你的DeepSeek钥匙    ← 如果你用 DeepSeek，填这里（上面留空即可）
BOT_ADMINS=[你的QQ号]               ← 把 你的QQ号 换成你的真实 QQ 号（数字，如 [123456789]）
DEFAULT_CITY=武汉                    ← 你所在的城市（用于天气）
```

3. 保存（`Ctrl + S`），关闭记事本

> 💡 **其他看不懂的配置项全部不用管**，留空就行，不影响启动。
> 想开启天气推送、校园通知等功能时，再回来填。

**✅ 怎么确认成功了**：`.env` 文件存在，里面 `DEEPSEEK_API_KEY=`（或 `MIMO_API_KEY=`）等号后面有你的钥匙，`BOT_ADMINS=` 里有你的 QQ 号。

## 9. 第七步：启动 XiaoNai！

### 9.1 启动主程序（bridge）

1. 打开命令行（回到第 5.2 节的方法），确保在 `D:\xiaonai`
2. 输入并回车：

```
python bridge.py
```

3. 你会看到一堆日志滚动，最后有类似 `WebSocket connected` / `开始工作` 的字样

**✅ 怎么确认成功了**：命令行里**没有红色的报错**，能看到 `connected` 之类的字样。

> 💡 这个黑窗口**不能关**，关了机器人就停了。想让它一直跑，最小化就行。

### 9.2 （可选）启动定时推送（scheduler）

再开一个新的命令行窗口（`Win + R` → `cmd`），输入：

```
cd /d D:\xiaonai
python scheduler_v5.py
```

这个负责定时推送天气、新闻、考试倒计时。不启动也不影响聊天功能。

## 11. 常见问题排查

| 现象 | 原因 | 解决办法 |
|------|------|---------|
| `python` 不是内部或外部命令 | Python 没装好 / PATH 没勾 | 重装 Python，勾选 "Add to PATH"，重开命令行 |
| `pip install` 报红字 | 网络问题或缺编译器 | 用清华镜像：命令后面加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| NapCat 窗口一闪而过 | QQ 没登录 | 先登录电脑 QQ，再启动 NapCat |
| `http://127.0.0.1:6099/webui` 打不开 | 端口不对 / NapCat 没启动 | 看 NapCat 黑窗口里的端口号；确认 NapCat 在运行 |
| bridge.py 报 `Connection refused` | NapCat 没配 OneBot 或端口不对 | 确认 NapCat WebUI 里 OneBot WebSocket 端口是 **3001** |
| 机器人不回复，但日志有 `401/403` | API Key 填错了 / 没充钱 | 检查 `.env` 里 Key 是否正确、服务商账户是否有余额 |
| 机器人回复"我不知道" | 知识库为空 | 正常现象，聊天功能可用；知识库按 [KNOWLEDGE-BASE-GUIDE.md](KNOWLEDGE-BASE-GUIDE.md) 自行添加 |
| 命令行中文乱码 | 编码问题 | 在命令行输入 `chcp 65001` 回车后再启动 |
| 端口 3001 被占用 | 其他程序占用了 | 换端口：NapCat 里改，同时改 `bridge.py` 和 `scheduler_v5.py` 里的 `3001` |

**万能重启大法**：出任何奇怪问题，先 `Ctrl+C` 关掉 bridge，再重新 `python bridge.py`。解决 80% 的玄学问题。
