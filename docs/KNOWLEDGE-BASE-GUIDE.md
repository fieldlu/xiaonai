# 知识库自建指南

小奈的知识库是一个**纯 Markdown 文件目录**，每个 `.md` 文件就是一个「知识条目」。检索时按文件名和内容匹配。

> ⚠️ **本项目不附带任何真实知识库内容**（避免版权和隐私问题）。本文档说明如何构建你自己的知识库。

---

## 一、目录结构

```
data/knowledge/
├── 2025本科选课手册.md          ← 一个知识条目 = 一个 .md 文件
├── 学生手册-学籍管理.md
├── 培养方案-机械工程.md
└── ...（你想让机器人知道的任何文档）
```

## 二、文件格式规范

### 2.1 命名

文件名就是检索关键词，建议包含「主题 + 分类」：

```
✅ 学生手册-奖学金.md
✅ 选课参考-高数.md
✅ 2026招生计划-湖北.md

❌ 文档1.md            ← 名字无意义，搜不到
❌ 新建文档(3).md
```

### 2.2 内容

用 Markdown，第一行用 `# 标题`（会被识别为主题）：

```markdown
# 国家奖学金申请指南

## 申请条件
- 学习成绩排名前 10%
- ...

## 申请流程
1. 登录系统提交申请
2. 学院审核
3. ...

## 常见问题
**Q: 需要什么材料？**
A: 成绩单、获奖证明...
```

### 2.3 格式建议

| 建议 | 原因 |
|------|------|
| 用 `##` 分节 | 检索时按 500 字切块，小节便于命中 |
| 重要数字/日期写全 | 「每年 9 月」「50 元」这类可被精确检索 |
| 文件名带分类前缀 | 便于 `_exec_course` 等专项路由命中 |
| 避免超长单文件 | 建议 <50KB，太长检索不准 |

## 三、构建索引

```bash
# 全量重建三套索引（BM25 + semantic + index）
python3 search/rebuild_kb_index.py

# 只重建 BM25
python3 -c "import kb_manage; kb_manage._bm25_build()"

# 只重建语义索引
python3 search/kb_semantic.py build
```

## 四、测试检索

## 五、检索优化技巧

### 5.1 口语问题答不对

小奈有 **MiMo 查询改写层**——口语问题先改写成检索关键词再搜。如果还答不对：

1. 检查文件命名是否含用户可能说的词
2. 内容里明确写出关键词（如文件名「选课参考」内容里要有「选课」）

### 5.2 想精确定位某段

把关键段落用 `##` 独立分节，检索时能命中小节：

```markdown
## 体育成绩评定
体育分由任课老师打，包括平时+体测+期末三部分。
```

### 5.3 培养方案类专项

`bridge.py` 的 `_exec_course` 会按「学期」切块注入培养方案。文件名需含专业名：

```
培养方案-机械工程-2024.md
```

## 六、隐私与合规

⚠️ **重要提醒**：

- ❌ **不要**放入真实同学的手机号/QQ号/家庭住址
- ❌ **不要**放入内部未公开文件
- ❌ **不要**上传有版权限制的教材/试卷
- ✅ 只放**你有权使用**的信息（学校公开章程、自己整理的学习资料等）

本项目对上传内容不承担责任，请自行确保合规。

## 七、知识库维护命令

```bash
python3 search/kb_manage.py list                  # 列出所有条目
python3 search/kb_manage.py view <主题>           # 查看条目
python3 search/kb_manage.py add <主题> <内容>     # 添加
python3 search/kb_manage.py update <主题> <内容>  # 更新
python3 search/kb_manage.py delete <主题>         # 删除
python3 search/kb_manage.py import <文件> [主题]  # 导入 docx/pdf/xlsx/txt
python3 search/rebuild_kb_index.py                # 重建索引
```
