# 示例知识库（school）

本目录是 XiaoNai 的**示例知识库**，收录武汉理工大学公开校情信息（新生攻略、选课评价、培养方案、学生手册要点、行政办法等），供部署后快速体验检索功能。

## 内容说明

| 前缀/类型 | 内容 |
|-----------|------|
| `武理新生攻略-*` / `武理攻略2026*` | 新生入学全流程攻略（报到/宿舍/军训/体测/奖学金等） |
| `WUT选课评价汇总-*` | 全校课程教师评价汇总（按 8 大类合并） |
| `汽车学院教师信息汇总-第N卷` | 汽车工程学院教师职称/研究方向（按姓氏分卷） |
| `学生手册-*` | 学生手册要点条目 |
| `武汉理工大学*` | 校级公开管理办法/通知 |
| 其余 | 选课手册、竞赛分级、培养方案等 |

## 隐私处理

已做如下脱敏，仍请使用者自行复核后再用于生产：

- ❌ 不含任何真实学生通讯录（姓名/QQ/手机号/学号/宿舍）
- ✅ 教师信息为学院官网公开职称资料
- ✅ 快递站/招新群等为学校公开发布的公务联系方式
- 🔒 WebVPN 带 token 的内链已替换为 `[WEBVPN]` 占位

## 使用方式

```bash
# 将本目录内容复制到你的运行时知识库
cp -r data/knowledge/school/*.md /path/to/runtime/data/knowledge/

# 重建索引
python3 search/rebuild_kb_index.py
```

> 知识库构建规范见 [docs/KNOWLEDGE-BASE-GUIDE.md](../../docs/KNOWLEDGE-BASE-GUIDE.md)。
