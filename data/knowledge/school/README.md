# 示例知识库（school）

本目录是 XiaoNai 的**示例知识库**，收录武汉理工大学公开校情信息（新生攻略、选课评价、培养方案、学生手册要点、行政办法等），供部署后快速体验检索功能。

## 内容说明

| 前缀/类型 | 内容 |
|-----------|------|
| `武理新生攻略-*` / `武理攻略2026*` | 新生入学全流程攻略（报到/宿舍/军训/体测/奖学金等） |
| `WUT选课评价汇总-*` | 全校课程教师评价汇总（按 8 大类合并） |
| `汽车学院教师信息汇总-第N卷` | 汽车工程学院教师职称/研究方向（按姓氏分卷，**联系方式已全部隐去**） |
| `学生手册-*` | 学生手册要点条目 |
| `武汉理工大学*` | 校级公开管理办法/通知 |
| 其余 | 选课手册、竞赛分级、培养方案等 |

## 隐私处理（严格模式）

本目录执行**联系方式零容忍**策略，所有个人联系方式一律掩码：

- ❌ 不含任何真实学生通讯录（姓名/QQ/手机号/学号/宿舍）
- ❌ 全部手机号（含公务联系人电话）→ `[电话已隐去]`
- ❌ 全部电子邮箱（含教师公开邮箱）→ `[邮箱已隐去]`
- ❌ WebVPN 带 token 的内链 → `[WEBVPN]` 占位
- ❌ 个人商业订场微信号 → `[订场微信]` 占位
- ✅ 保留：院系办公座机总机、QQ 招新群号（公开发布的入群入口）、课程评价文本
- 🔒 扫描脚本验证：15+ 敏感模式 + 手机号 + 邮箱正则 = **0 命中**

> 如需还原完整联系方式用于自己班级部署，请自行向学院/辅导员获取，勿从历史版本找回。
